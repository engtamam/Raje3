# نقاط الولاء — الكونسول مقابل الجوال

**الحالة:** مكتملة (9/9) — بُنيت 2026-09-23، تحقّق مباشر من `apps/console/src/screens/Points.tsx` مقابل `apps/mobile/lib/features/points/points_screen.dart`، سطرًا بسطر، بهوية بصرية مختلفة تمامًا (خزانة ذهبية/بنفسجية، بطاقات مكافآت متدرّجة الفئة، لوحة صدارة) بدل جدول إداري. مُتحقَّق منها حيًا بالمتصفح.

**تصحيح عن الصف القديم بهذا الملف**: "رصيد النقاط الحالي وتاريخه" ليست جزءًا من هذي الشاشة أصلًا بالكونسول — هذي بيانات عميل واحد، مبنية من قبل تحت شاشة عملائي (`customer_detail_screen.dart`، ✅ موجودة). «نقاط الولاء» شاشة المالك الإدارية: كتالوج المكافآت وتقرير البرنامج.

| الميزة | الكونسول | الجوال |
|---|:---:|:---:|
| قائمة المكافآت (فعّالة ومتوقفة) | ✅ | ✅ |
| إضافة مكافأة (خدمة من الكتالوج / هدية / خصم مبلغ) | ✅ | ✅ |
| تعديل مكافأة (الاسم، الثمن بالنقاط، قيمة الخصم) | ✅ | ✅ |
| إيقاف/إعادة تفعيل مكافأة | ✅ | ✅ |
| تقرير البرنامج: النقاط المعلّقة، الممنوحة، المستهلكة | ✅ | ✅ |
| تحذير النقاط المنتهية بلا استبدال (نسبة عالية) | ✅ | ✅ |
| الأكثر طلبًا من المكافآت (لوحة صدارة) | ✅ | ✅ (الجوال أوسع بصريًا — ميداليات وأشرطة تقدّم بدل جدول) |
| وضع الكسب (نقاط لكل خدمة أو نقطة لكل ريال بالفاتورة) | ✅ | ✅ |
| الوصول لإعدادات نقاط كل خدمة | ✅ | ✅ (رابط حقيقي لشاشة خدماتي ومنتجاتي، مو نسخة ثانية من نفس المحرر) |

**لا فجوات متبقية.**

**ملاحظة معمارية مقصودة**: تفاصيل إعدادات الكسب (كم نقطة لكل خدمة على حدة) لم تُكرَّر بهذي الشاشة —
نفس البيانات الحقيقية مبنية أصلًا تحت «خدماتي ومنتجاتي» بنفس الجلسة (`services_screen.dart`). هذي
الشاشة توفّر رابطًا حقيقيًا لها بدل محرّر ثانٍ لنفس الأرقام، اللي يعني نسختين ممكن تختلفان. وضع
الكسب نفسه (بالخدمات/بالفاتورة) بُني هنا مباشرة لأنه مفتاح البرنامج نفسه ومكانه الطبيعي جنب التقرير
اللي يشرح أثره — بُني بنفس الشرط الحقيقي من الباكند (لازم كل الخدمات مسعّرة عشان يفعّل وضع الفاتورة)
ونفس رسالة الرفض الحقيقية لو رُفض التبديل.
