# حسابي والفروع — الكونسول مقابل الجوال

**الحالة:** جزئية (10/12) — تحديث 2026-09-23: أضيف تعديل/إيقاف/تفعيل الموظف وساعات العمل داخل بطاقة فريق كل فرع (قرار معماري متعمّد بالتطبيق: الفريق يعيش داخل صفحة الفرع، لا شاشة "فريقي" عامة منفصلة زي الكونسول).

| الميزة | الكونسول | الجوال |
|---|:---:|:---:|
| هوية المحل (الاسم، الشعار، اللون) | ✅ | ✅ |
| قائمة الفروع وتفاصيل كل فرع | ✅ | ✅ |
| رابط الموقع على الخرائط لكل فرع | ✅ | ✅ |
| الفوترة وحالة الاشتراك | ✅ | ✅ |
| اسم المالك على شاشة الحساب | ✅ | ✅ |
| توظيف موظف جديد (اسم/جوال/كلمة مرور/دور/فرع) | ✅ | ✅ |
| تعديل موظف (الاسم، الدور، نقل الفرع) | ✅ | ✅ |
| تحديد أي فروع يشوفها الموظف (فرعه/محددة/الكل) | ✅ | ✅ |
| إيقاف موظف وإعادة تفعيله | ✅ | ✅ |
| ساعات عمل الموظف (لكل يوم، أو تبعية ساعات المحل) | ✅ | ✅ |
| ملاحظات المحل للمساعد الذكي عبر واتساب | ✅ | ❌ (مؤجَّل — لحد ما يُبنى تطبيق المساعد الذكي عبر واتساب) |
| حد كلمات رسائل العميل (إعداد المساعد الذكي) | ✅ | ❌ (نفس التأجيل أعلاه) |
