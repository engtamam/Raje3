# الرحلات

الرحلة هدفٌ أو موقف، لا تبويب. اسم الملف فعلٌ إنجليزي قصير، والعنوان العربي داخله.

record-visit          عميل واقف عندك الحين — سجّل زيارته في خمس ثوانٍ
redeem-reward         عميل جمع نقاطه ويبغى مكافأته
apply-offer           عميل وصله عرض — طبّقه على زيارته
stop-message          رسالة على وشك الخروج وما تبغاها
add-service           بدأت تقدّم خدمة جديدة
price-points          تبغى تغيّر نقاط خدمة أو مكافأة
bring-back-lapsed     ناس ما جوك من زمان — رجّعهم بحملة
connect-whatsapp      ربط رقم محلك أول مرة
add-teammate          موظف جديد يحتاج دخول
erase-customer        عميل طلب حذف بياناته
