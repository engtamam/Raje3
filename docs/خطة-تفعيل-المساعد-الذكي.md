# خطة: تفعيل المساعد الذكي (خدمة عملاء + مساعدة سياقية) على المنصات الثلاث

## السياق والقرار

المصدر: `platform/services/assistant-service` — خدمة مساعد معرفة جاهزة (منشورة فعلاً، `v0.18.29`،
`sha256:56c6722cfa1c3148530490d71584ccffb59a985515eb2e4b21f3b776892ba5af`)، مبنية على قاعدة معرفة
(kb) بدل حشو الطلب كامل، تجاوب باقتباس مباشر (بلا ذكاء اصطناعي خارجي) أو بمزوّد حقيقي لاحقًا.

**قرار أساسي:** ثلاث منصات مستقلة (المحل، الإدارة، المسوّقين) — كل وحدة كتالوجها الخاص، بلا أي
تسرّب بين الأفعال. الشرح اليدوي العميق (لأي شي غير الأفعال — عناوين أعمدة، مصطلحات) **يقتصر على
منصة المحل حاليًا** فقط (عميلنا الحقيقي) — الإدارة والمسوّقين يكتفون بالتوليد التلقائي، نرجع لهم
لاحقًا لو احتجنا.

**قرار عزل:** أيقونة "؟" (شرح سريع بلا ذكاء اصطناعي) والمحادثة الذكية (شات كامل) إعدادان منفصلان
تمامًا (true/false لكل وحدة لحالها) — أربع تركيبات ممكنة.

## القرارات الأمنية والامتثال المُتَّخذة (لا تُعاد مناقشتها بدون سبب جديد)

- **حذف المحادثات (privacy-first):** بشكل افتراضي، حذف عميل = حذف حقيقي، بما فيه أي رابط يفك
  تشفير بصمته. هذا مطابق لأفضل الممارسات المعتمدة عالميًا (Crypto-Shredding، معترف بها من EDPB
  وICO وCNIL) — راجع محادثة الجلسة نفسها للمصادر.
- **الاستثناء الوحيد:** بلاغ قانوني حقيقي **قبل** طلب الحذف (لا مجرد "احتياط عام" — هذا غير كافٍ
  قانونيًا لوحده).
- **سجل الـaudit لا يُحذف أبدًا** (تصميم متعمَّد، `core/erasure.py` بخدمة الفريق الشريك) — يحتفظ
  بالبصمة (محل + عميل مشفّر + وقت) للأبد، بلا نص، بلا إمكانية فك تشفير — هذا يوفّر إثبات "صار شي"
  حتى بعد الحذف الكامل، بدون كشف هوية.
- **معرّف المحل:** المعرّف الداخلي بالنظام، لا رقم الجوال (ثابت، ما يتكرر).
- **معرّف العميل:** بصمة مشفّرة أحادية الاتجاه (HMAC، لا تشفير قابل للعكس) — نفس `subject_ref`
  المستخدم بكل مكان بالمنصة.

## المتطلبات المفتوحة عند الفريق الشريك (٤ نقاط، أُرسلت، بانتظار الرد)

1. تنفيذ `core/erasure.py` (حذف حقيقي عند طلب DSAR) — TODO عندهم حاليًا.
2. تسجيل حدث تدقيق عند كل حذف جماعي بجدولة الاحتفاظ (`POST /internal/assistant/retention`) —
   غير مُسجَّل إطلاقًا اليوم.
3. بصمة إسناد لكل رسالة معالَجة (نفس `whatsapp_assistant.message_attributed` اللي بنيناها نحن).
4. تصفّح صفحات (pagination) على `GET /api/v1/audit` — محدود بـ١٠٠٠ بلا طريقة تجاوزه.

يُضاف لقسم "القرارات" أعلاه، لا يُناقَش من الصفر في محادثة لاحقة.
